查询用户详情信息

● 已发布
GET https://api.shop.com /api/v1/users/{user_id}/profile

根据传入的 user_id 获取指定用户的个人档案、VIP 订阅状态以及最近一笔交易快照。调用此接口需要在 Header 中传入有效的 Bearer Token。

请求参数 (Request Parameters)

Path 参数
参数名 类型 必填 说明与示例值
user_id string 必填 全局唯一用户 ID 示例: usr_9823471
Query 参数
参数名 类型 必填 说明与示例值
include_orders boolean 可选 是否附带返回最近订单列表，默认 false

返回响应 (Responses)

200 成功 401 未授权
code integer 必填
状态码，0 代表成功
message string
提示信息
data object
用户详情核心载荷
user_id string
用户唯一 ID
nickname string
用户显示昵称
vip_status boolean
是否为有效 VIP 会员 
curl --location --request GET \
  'https://api.shop.com/api/v1/users/usr_9823471/profile?include_orders=true' \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  --header 'Accept: application/json'
